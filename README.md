# 🏢 Sistema de Gestão de RH e Banco de Horas

Um sistema de linha de comando (CLI) desenvolvido em Python para automatizar o cadastro de funcionários, gestão de status (ativos/desligados) e o cálculo de banco de horas diário.

## 🚀 O Problema que Resolve
Muitas pequenas empresas ainda controlam seus funcionários e horas extras em cadernos ou planilhas desorganizadas. Este sistema visa simplificar esse processo, permitindo o registro rápido de entrada e saída, calculando automaticamente o saldo de horas do dia com base na jornada de trabalho estabelecida.

## ⚙️ Funcionalidades
- **Cadastro Completo:** Registro de nome, cargo, salário e jornada de trabalho.
- **Gestão de Status:** Filtro e listagem de funcionários Ativos e Desligados.
- **Atualização de Dados:** Edição de cargo, salário e alteração de status (Ativar/Desligar).
- **Cálculo de Banco de Horas:** Entrada de horários (início, almoço, saída) com cálculo automático de horas trabalhadas e saldo do dia.
- **Cálculo Financeiro:** Cálculo automático do valor da hora do funcionário com base na jornada mensal.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Bibliotecas:** `datetime` (nativa) para cálculo exato de tempo.
